## 구조

- `index.html` — 주차별 아카이브 랜딩
- `weeks/NN-slug/` — 각 주차의 독립 정적 사이트 (기본: 순수 HTML/CSS/JS, 의존성 없음)
- push하면 GitHub Pages가 자동 배포

## 규칙

- 주 1개, 주말~일주일 규모
- 처음 본 사람이 30초 안에 웃거나 공유하고 싶어지면 성공
