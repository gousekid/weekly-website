# Requirements

## 프로젝트 공통 목표
- 매주 1개, 작고 재미있는 웹사이트를 완성하고 공개 URL로 배포한다.
- 각 사이트는 "처음 본 사람이 30초 안에 웃거나 공유하고 싶어지는" 것을 성공 기준으로 삼는다.

## 공통 제약
- 주차당 작업 규모는 주말~일주일 이내.
- 모바일/데스크톱 모두에서 깨지지 않아야 한다.
- 서버 없이 정적 호스팅으로 배포 가능해야 한다(백엔드가 필요한 주차는 명시적으로 결정 후 진행).

## Week 01: 오늘의 퇴사 사유 생성기
### 목표
사직서 문서 모양의 페이지에서 버튼을 누르면 재미있는 퇴사 사유가 랜덤으로 채워진다.

### 기능 요구사항
- [필수] 사유 랜덤 생성: 진지 모드(그럴듯+위트) / 광기 모드(황당) 각각 20개 이상의 사유 풀.
- [필수] 사직서 문서 UI: 소속/직급/성명 입력 가능, 오늘 날짜 자동, 성명 기반 도장 표시.
- [필수] 이미지 저장: 완성된 사직서를 PNG로 다운로드.
- [필수] 공유: Web Share API, 미지원 브라우저는 클립보드 복사 폴백.
- [선택] 사유 뽑기 시 슬롯머신풍 텍스트 셔플 애니메이션.

### 비목표
- 로그인, 저장, 랭킹 등 서버 기능 없음.
- 사유 풀의 사용자 편집 기능 없음.

### 성공 기준
- 데스크톱/모바일 브라우저에서 뽑기→이미지 저장→공유 흐름이 동작한다.
- 페이지 로드 후 조작 없이도 사유 하나가 채워져 있다(빈 문서로 시작하지 않음).
